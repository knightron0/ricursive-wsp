Design: The first hidden layer encodes ball column (units 0–9), paddle column (units 10–19), and ball horizontal direction within row bands 3–8 (units 20–31). The second layer is an identity pass-through. The output layer computes a target column for the paddle: if the ball is moving down in rows 3–8, it extrapolates its horizontal velocity to row 8 and moves toward that column; otherwise it tracks the ball’s column. No-op is chosen when the target is within ±1/3 column of the paddle, left/right otherwise.
